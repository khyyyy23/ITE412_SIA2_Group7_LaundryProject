## Project Summary

SPNRCO is a laundry booking app that allows customers to book laundry services through an online system. Customers can choose their preferred laundry service, provide their laundry details, and select a schedule for their booking. The laundry shop can manage customer bookings and update their status. The system aims to make the laundry booking process more organized and convenient for both customers and the shop.
